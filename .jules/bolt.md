## 2026-03-30 - Module-level pre-compiled regexes & exact match lookup map in referral fee classification
**Learning:** In referral fee string normalization loops (`normalize_csv_override`), linear tuple scanning through list aliases (`CSV_OVERRIDE_ALIASES`) incurs non-trivial iteration overhead when normalizing large volumes of items/CSV overrides. Creating a module-level `CSV_EXACT_MAP` dictionary provides an $O(1)$ fast-path lookup for exact key matches. Pre-compiling word-boundary regex patterns (`\bwatches\b`, `\bpc\b`) at module load avoids repeated regex string compilation overhead inside classification heuristics (`classification_texts_to_bucket`).
**Action:** Always create fast $O(1)$ lookup dictionaries for alias lists and pre-compile regular expressions at module scope when writing text classification or normalization functions that execute on hot ingestion loops.
