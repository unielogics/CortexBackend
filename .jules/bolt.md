## 2025-08-10 - Pre-computing geographic coordinates in radians and caching lookups
**Learning:** In the contiguous U.S. state mapping functions like `nearest_contiguous_state_for_zip3`, repeatedly calling `math.radians` on the fixed 48 state hub coordinates during distance checks creates a bottleneck in hot loops. Pre-computing coordinates in radians at the module level yields a ~34% speedup on raw cache-miss lookups, while decorating the outer-facing function with an `@lru_cache(maxsize=1024)` completely bypasses string processing and distance loops on subsequent calls, resulting in an overall ~14.5x speedup.
**Action:** Always pre-compute static configurations/reference datasets (like coordinates) in their final processed format (e.g., radians, floats) at the module level. Use a dedicated `@lru_cache` on the outermost function to avoid redundant cleaning and loop processing.
