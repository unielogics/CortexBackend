## 2026-07-21 - Nearest State ZIP3 Lookup Cache & Pre-computation
**Learning:** Geographic distance calculations against a static set of hubs (like `CONTIGUOUS_STATE_HUB_DESTINATIONS_48`) are frequently performed on ZIP3s (which are highly clustered and capped at ~1,000 unique values). Performing math.radians, float casts, and dict lookups in a hot loop for every call is a major performance bottleneck. Pre-computing coordinates in radians at the module level avoids loop overhead completely, and decorating the main function with `lru_cache` yields massive O(1) performance benefits.
**Action:** Always pre-compute static configurations/coordinates at the module level in radians or float arrays when performing spatial lookups against static locations, and cache ZIP-based lookups.
