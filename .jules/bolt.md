## 2025-08-05 - Distance Math Pre-computation & Cache
**Learning:** Repeatedly calculating distances using full Haversine formula against a static, fixed pool of locations (e.g., `CONTIGUOUS_STATE_HUB_DESTINATIONS_48`) inside hot loops introduces severe CPU overhead due to redundant radians conversion, trig functions, and string-to-float conversions. Using the Spherical Law of Cosines is mathematically equivalent for finding the closest hub (minimizing distance) but requires far fewer trig calls (maximizing the cosine of the central angle). By pre-computing sines and cosines of the static hubs at the module level, we can run only 1 `math.cos` call inside the loop. Additionally, adding `@functools.lru_cache` on such idempotent computations yields massive O(1) performance improvements for warm calls.
**Action:** When finding nearest locations against a static list of points, pre-compute trig values of coordinates at the module level, use the Spherical Law of Cosines for distance comparison, and decorate with `@functools.lru_cache`.
